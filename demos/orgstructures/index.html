Организационные структуры управления 10 предприятий

По одной схеме на организацию: иерархия органов управления сверху вниз, контрольные и коллегиальные органы — сбоку. Реквизиты взяты из карточек предприятий, сама структура построена по организационно-правовой форме.

Акционерное обществоАкционеры → Общее собрание акционеров → Совет директоров → Правление → Генеральный директор → подразделения
Общество с ограниченной ответственностьюУчастники → Общее собрание участников → Генеральный директор → подразделения
Образовательное учреждениеУчредитель → Руководитель → Администрация → структурные подразделения → педагогический персонал
Медицинское учреждениеУчредитель → Главный врач → Заместители → медицинские и административно-хозяйственные подразделения

Карточки содержат только реквизиты и не описывают органы управления. Поэтому все органы, кроме собственников, подписаны «типовая учебная модель». Это не официальная структура конкретной организации. Имена приведены только так, как они указаны в карточке в поле «Учредители».
