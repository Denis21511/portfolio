# Портфолио студии

Статический сайт без сборки: `index.html`, `assets/css/main.css`, `assets/js/app.js`, контент в `assets/js/data.js`.
Работает на любом статическом хостинге (GitHub Pages, Netlify, обычный сервер). Навигация через `#/…`, поэтому 404 при обновлении страницы не будет.

## Локальный просмотр

```
npx http-server . -p 5200 -c-1
```

и открыть http://localhost:5200.

## Что заполнить перед публикацией

В `assets/js/data.js`, объект `STUDIO`:

- `name` — название студии (сейчас «Studio»);
- `email`, `telegram`, `phone` — контакты. Пока они пустые, форма на странице Contact показывает подсказку, куда их вписать.

## Структура

| Путь | Что там |
|---|---|
| `assets/work/<id>/` | полноразмерные скриншоты проекта |
| `assets/thumbs/<id>/` | превью 960px для папок и карточек |
| `demos/` | живые копии проектов без сервера: «Даль» и «Оргструктуры» |
| `tools/make-thumbs.mjs` | пересборка превью |

## Как добавить проект

1. Положите скриншоты в `assets/work/<id>/`.
2. Добавьте объект в `PROJECTS` в `assets/js/data.js` (поля описаны в комментарии над массивом).
3. Соберите превью: `npm i playwright-core && node tools/make-thumbs.mjs <id>` (нужен Google Chrome).
   Без превью сайт тоже работает: подставит полноразмерные картинки.

Категории берутся из `CATEGORIES`. Папка появляется на главной, только если в категории есть хотя бы один проект,
номера 01, 02… раздаются автоматически. DESIGN и BRANDING уже описаны и появятся сами, когда в них будут работы.

## Откуда материалы

Скриншоты сняты с реальных файлов проектов в соседних папках (`dobrovet`, `goldskin`, `starker`, `dal`,
`autoparts-widgets`, `tilda-widgets`, `2gis-leads`, «Оргструктуры десяти предприятий.html»), мобильные коллажи
и виджеты Tilda — исходные PNG из папок `screenshots`. Диалог бота собран из текстов `order_bot/texts.py`,
`keyboards.py` и `handlers/`. Таблица компаний из исследования 2ГИС в портфолио не выводится, только сводные цифры по нишам.
